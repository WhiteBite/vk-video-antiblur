# VK Video AntiBlur

Юзерскрипт для Tampermonkey / Violentmonkey, который убирает размытие превью и скрывает оверлей «Видео с возрастным ограничением» на [VK Видео](https://vkvideo.ru) и vk.com.

VK убрал из настроек галочку «Не размывать превью», и теперь миниатюры всех видео с пометкой 18+ размыты всегда — включая обычные фильмы. Этот скрипт возвращает превью как было.

## Что делает

- Снимает `filter: blur()` с миниатюр видео на страницах видео, в рекомендациях и поиске.
- Скрывает оверлей возрастного ограничения, закрывающий превью в плеере.
- Работает с динамической подгрузкой (бесконечный скролл) и SPA-навигацией без перезагрузки страницы.

## Чего НЕ делает

- Не обходит серверную проверку возраста при воспроизведении: если VK требует вход в аккаунт 18+ для просмотра, скрипт этого не меняет. Он убирает только визуальное размытие превью.
- Не скачивает видео и не ломает рекламу.

## Установка

1. Установите менеджер юзерскриптов:
   - [Tampermonkey](https://www.tampermonkey.net/) (Chrome, Firefox, Edge, Opera, Safari)
   - или [Violentmonkey](https://violentmonkey.github.io/) (open source)
2. Откройте ссылку установки:
   **[Установить vk-video-antiblur.user.js](https://raw.githubusercontent.com/WhiteBite/vk-video-antiblur/main/vk-video-antiblur.user.js)**
3. Подтвердите установку в открывшемся окне менеджера скриптов.

Обновления прилетают автоматически через `@updateURL` при выходе новой версии.

## Почему не готовые скрипты с GreasyFork

На момент создания единственный живой аналог (ULTIMATE v2) сломан: в его CSS-фолбэке опечатка в селекторе (`video_card_resctriction_overlay` вместо реального `video_card_restriction_overlay`), а селектор `img[class*="blur"]` не находит ничего, потому что VK применяет блюр через хэш-классы вида `vkit-GYi7Eq`, в которых нет подстроки «blur».

## Как это работает

Скрипт не угадывает имена CSS-классов VK (они хэшированы и меняются от сборки к сборке, а сами правила лежат в кросс-доменных стилях CDN и недоступны для сканирования). Вместо этого три независимых слоя:

1. **Статичный CSS** — прячет оверлей по стабильному атрибуту `data-testid="video_card_restriction_overlay"`.
2. **Детект по computed-стилю** — `MutationObserver` проверяет каждое добавленное изображение: если у него вычисленный `filter` содержит `blur()`, ставится инлайн-оверрайд `filter: none !important`, который побеждает любой класс.
3. **Периодический sweep** — раз в 3 секунды (только после изменений DOM) догоняет случаи, когда React переиспользует существующий узел и меняет ему класс без добавления новых узлов.

Плюс страховка: если VK переименует `data-testid` оверлея, он прячется по комбинации «`backdrop-filter: blur` + текст про возрастное ограничение».

## Совместимость

- `vkvideo.ru` (включая `live.vkvideo.ru`) — проверено
- `vk.com`, `vk.ru` — матчи заложены на случай встроенных плееров; сам раздел vk.com/video сейчас редиректит на vkvideo.ru
